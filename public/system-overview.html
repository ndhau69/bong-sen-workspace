Các màn hình nghiệp vụ

  1. Dashboard: KPI quản trị & 4 biểu đồ thống kê.
  2. Khách hàng (CRM): Chi tiết 360°, Import Excel / Google Sheets.
  3. Hồ sơ dịch vụ: Tạo, lọc, theo dõi tiến độ & công nợ.
  4. Công việc: Theo dõi bước xử lý, cảnh báo sắp hạn/quá hạn.
  5. Kanban: Kéo thả 8 cột trạng thái + Realtime.
  6. Nhân viên: Hiệu suất phụ trách theo nhân sự.
  7. Tài chính: Hợp đồng, đặt cọc, thu tiền, chi phí, công nợ.
  8. Tài liệu: Thư mục, upload, xem trước PDF/Ảnh, phân quyền.
  9. Báo cáo: 6 báo cáo lọc đa điều kiện + Xuất Excel.
  10. Cài đặt: Dịch vụ, quy trình mẫu, phòng ban, Audit Log, Google Sheets.
  11. User & Phân quyền: Tạo/Sửa User, Show/Hide màn hình theo Role & từng User.

Quy trình Cập nhật, Backup & Rollback

  • Chạy test local: cd d:\bong-sen-workspace && npm run dev (kiểm tra trước khi đẩy).
  • Đẩy code & Deploy: git add . && git commit -m "..." && git push origin main
    • Tự động tạo file .zip backup vào d:\Backup\bong-sen-workspace\ (qua .git/hooks/pre-push).
    • Tự động lưu code & snapshot 90 ngày trên GitHub.
    • Cloudflare Pages tự động build và phát hành bản mới lên https://ws.thuebongsen.online (và bong-sen-workspace.pages.dev).
  • Rollback khi cần:
    • Quay về mốc chuẩn đầu tiên: yêu cầu rollback về tag v1.0 trên GitHub.
    • Quay về thời điểm bất kỳ: chọn file .zip theo ngày giờ trong d:\Backup\bong-sen-workspace\ hoặc rollback trực tiếp deployment trên Cloudflare Pages.
    • Lưu ý Database: Rollback code không tự hoàn tác dữ liệu đã nhập trong PostgreSQL; nên xuất Excel hoặc đồng bộ Google Sheets định kỳ để sao lưu dữ liệu nghiệp vụ.
